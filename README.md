# goit-pycore-hw-07

Домашнє завдання №7 (Тема 10) — розширене об'єктно-орієнтоване програмування в Python.

Консольний бот-помічник з адресною книгою: зберігає контакти з телефонами
та днями народження, підказує кого треба привітати найближчим тижнем.
Продовження ДЗ №6 — до класів `Record` та `AddressBook` додано роботу
з днями народження.

## Запуск

```bash
python task_1.py         # інтерактивний бот
python task_1.py demo    # демонстрація роботи AddressBook
```

Потрібен Python 3.10+. Зовнішніх залежностей немає.

## Команди

| Команда | Опис |
| --- | --- |
| `hello` | Привітання від бота |
| `add [ім'я] [телефон]` | Додати контакт або новий телефон до наявного контакту |
| `change [ім'я] [старий телефон] [новий телефон]` | Змінити телефонний номер контакту |
| `phone [ім'я]` | Показати телефони контакту |
| `all` | Показати всі контакти |
| `add-birthday [ім'я] [DD.MM.YYYY]` | Додати дату народження |
| `show-birthday [ім'я]` | Показати дату народження контакту |
| `birthdays` | Кого вітати протягом наступних 7 днів |
| `help` | Список команд |
| `close` / `exit` | Закрити програму |

## Структура

| Клас | Призначення |
| --- | --- |
| `Field` | Базовий клас поля запису |
| `Name` | Ім'я контакту, обов'язкове поле |
| `Phone` | Телефон, валідація: рівно 10 цифр |
| `Birthday` | День народження, валідація формату `DD.MM.YYYY` |
| `Record` | Запис: ім'я, список телефонів, необов'язковий день народження |
| `AddressBook` | Колекція записів (`UserDict`) з пошуком та `get_upcoming_birthdays` |

Декоратор `input_error` перехоплює `ValueError`, `KeyError` та `IndexError`
і повертає користувачу зрозуміле повідомлення замість трейсбеку. Підказка про
формат команди підбирається під конкретний обробник.

## Валідація

- Телефон — рівно 10 цифр, інакше `Phone number must contain 10 digits.`
- Контакт не створюється, якщо телефон не пройшов валідацію
- Дата народження — формат `DD.MM.YYYY`, інакше `Invalid date format. Use DD.MM.YYYY`
- Дата народження в майбутньому відхиляється
- Дублікати телефонів у межах одного контакту не додаються
- Порожнє ім'я відхиляється

## Дні народження

`get_upcoming_birthdays()` повертає контакти, у яких день народження припадає
на найближчі 7 днів. Якщо дата випадає на суботу чи неділю, привітання
переноситься на понеділок. 29 лютого у невисокосний рік вважається 1 березня.
